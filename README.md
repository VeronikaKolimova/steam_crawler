# steam_crawler
# Steam Games Analysis &amp; Visualization  > Industrial-grade web scraping, data analysis, and visualization of 1000+ top-selling Steam games

##  **Project Overview**
Проект демонстрирует полный цикл работы с данными: от сбора через веб-скрапинг до продвинутой визуализации. 
Анализирует 1000+ самых продаваемых игр на платформе Steam, выявляя тренды, популярные теги и эволюцию игровых жанров.

### **Key Insights Discovered:**
- **Эволюция игровых тегов** с 2004 по 2026 год
- **Топ-3 популярных тега** для каждого года выпуска
- **Наименее популярные нишевые теги**
- **Корреляция** между тегами и годами выпуска

## **Tech Stack**
| Технология | Назначение |
|------------|------------|
| **Scrapy** | Промышленный веб-скрапинг с рекурсивным обходом |
| **Pandas** | Обработка и анализ данных |
| **Matplotlib/Seaborn** | Статическая визуализация |
| **WordCloud** | Текстовая визуализация тегов |
| **BeautifulSoup** | Дополнительный парсинг HTML |
| **Jupyter** | Интерактивный анализ |

##  **Key Features**

###  **Advanced Web Scraping**
- Рекурсивный обход пагинации Steam
- Обход возрастных ограничений (18+) через cookies
- Обработка JavaScript-контента
- Уважительный scraping с задержками

###  **Data Analysis**
- Группировка игр по годам выпуска
- Статистика популярности тегов
- Выявление трендов и паттернов
- Обработка пропущенных значений

###  **Visualization**
- **Heatmap**: Эволюция популярных тегов по годам
- **WordCloud**: Частота нишевых тегов
- **Scatter Plot**: Распределение тегов во времени

# Dataset Information
Collected Fields:
- title: Название игры
- release_date: Дата выпуска
- developer: Разработчик
- publisher: Издатель
- tags: Пользовательские теги (до 20 на игру)
- url: Ссылка на страницу Steam

### Statistics:
- 1000+ игр из раздела "Top Sellers"
- 20+ лет охвата (2004-2026)
- 200+ уникальных тегов
